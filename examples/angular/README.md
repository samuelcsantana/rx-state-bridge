# rx-state-bridge — Angular example

Live demo of every operator, one card each, using Angular Signals as the `StateIndicator`. Runs against a fake in-memory API (no real network).

```bash
npm install
npm run start   # ng serve, http://localhost:4200
```

Generated with Angular CLI (standalone components, zoneless, no routing/SSR/tests — this is a demo, not a template for a full app).
